# Manual del evaluador

1. Entra con una cuenta activa. Solo aparecen instrumentos que administración te asignó.
2. Abre **Evaluación** y revisa la evidencia, sus atributos y los archivos que tu asignación permite consultar.
3. Registra estado, resultado/comentario conforme al flujo institucional configurado. Las transiciones pueden requerir motivo; una evaluación cerrada requiere autorización administrativa para reabrirse.
4. Consulta el historial para revisar cambios anteriores. Los eventos históricos no se editan desde la interfaz.
5. Genera descargas únicamente desde instrumentos asignados. Si un instrumento no aparece, solicita que revisen tu asignación.

La propuesta de clasificación documental no sustituye la evaluación ni constituye dictamen. No uses coincidencia automática como aprobación.
